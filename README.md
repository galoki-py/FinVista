# FinVista: Financial Literacy Platform

FinVista is a hyper-local, offline-first financial literacy platform designed for undergraduates. This monorepo contains the mobile application, web interface, and the backend server.

## 🚀 Quick Start

1. **Clone the repository:**
   ```bash
   git clone https://github.com/galoki-py/FinVista.git
   cd FinVista
   ```

2. **Install Dependencies:**
   ```bash
   npm install
   ```

3. **Set up Environment Variables:**
   Copy the example environment files (see [SETUP.md](./SETUP.md) for details).

4. **Run Development Mode:**
   ```bash
   npm run dev
   ```

## 📂 Project Structure

- `apps/mobile`: React Native (Expo) mobile application.
- `apps/web`: React.js web application.
- `server`: Node.js Express backend with MongoDB and Gemini AI integration.
- `packages/`: Shared packages and types.
